# 印占星空图

打开网页即可查看**当前时刻**的三维恒星黄道星空。默认地点是北京，时间使用你浏览器的本地时区。

- 手机：单指拖动旋转，双指缩放
- 电脑：拖动鼠标旋转，滚动滚轮缩放
- 点「自动旋转」让星空自己慢慢转，再点一下就停
- 点「设置」可更改日期、时间、时区和地点，然后点「生成」
- 右下角是五历（月日、月宿、瑜伽、羯兰那、曜日、沙迦年）和 Lahiri 岁差

计算全程在你自己的浏览器里完成，不会上传时间或地点。

也可以用网址参数指定某一刻，例如：

`?date=2026-01-01&time=12:00:00&tz=Asia/Shanghai&lat=39.904&lon=116.407&place=北京`

还支持 `dt`（如 `2026-01-01T12:00:00`）、`timezone`、`view`、`rotate`。
